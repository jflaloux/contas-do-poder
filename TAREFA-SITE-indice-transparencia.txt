TAREFA PARA O AGENTE DO SITE — Índice de Transparência dos estados (01/10/2026)

O que mudou nos dados
---------------------
`python3 coletar.py indice` (também roda no `tudo`) agora gera DOIS arquivos:
- site/dados/indice.json — o de hoje (só governadores). Continua igual, para a página /indice atual não quebrar.
- site/dados/indice_transparencia.json — NOVO: o Índice de Transparência do Estado, com um bloco para o governo e um
  para a Assembleia Legislativa. É este que a página deve passar a mostrar.

O pedido do Jean-François: o índice é de acesso aos dados POR ESTADO, não "dos governadores". Nome: "Índice de
Transparência".

Formato de site/dados/indice_transparencia.json
-----------------------------------------------
{
  "meta": {
    "titulo": "Índice de Transparência dos estados",
    "pergunta": "Dá para saber, pela fonte oficial de cada Estado, quanto ganham e quanto custam os seus políticos?",
    "conferido_em": "2026-10-01",
    "como": [ ...5 frases do método, para mostrar na página... ],
    "blocos": [
      {"id": "governo", "titulo": "Governo do Estado", "pergunta": "...",
       "criterios": [{"id": "nome", "dimensao": "completude", "nome": "Nome", "como_pontua": "1 = ...; 0,5 = ...; 0 = ..."}, ...]},
      {"id": "assembleia", "titulo": "Assembleia Legislativa", "pergunta": "...", "criterios": [...]}
    ]
  },
  "estados": [   // os 27, em ordem de UF
    {"uf": "PE", "nome": "Pernambuco",
     "indice": 0.944,              // média dos índices dos blocos; null se algum bloco está a conferir
     "a_conferir": [],             // ids dos blocos sem nota (ex.: ["assembleia"])
     "blocos": {
       "governo":    {"indice": 0.983, "completude": 0.967, "facilidade": 1.0,
                      "criterios": {"nome": {"v": 1, "prova": "Nome completo"}, "lei": {"v": 1, "prova": "...", "link": "https://..."}, ...},
                      "a_conferir": [],   // ids dos critérios com v null
                      "fonte": "https://..."},   // a consulta oficial (pode ser uma página, um arquivo ou uma API)
       "assembleia": {"indice": 0.905, "completude": 0.875, "facilidade": 0.938, "criterios": {...}, "a_conferir": [], "fonte": "https://..."}
     }}
  ]
}
- Todas as notas vão de 0 a 1 (valores possíveis: 0; 0,2; 0,25; 0,4; 0,5; 0,6; 0,75; 0,8; 1). v null = "a conferir".
- índice do bloco = média harmônica de completude e facilidade; índice do Estado = média dos blocos.
- Os critérios de cada bloco (nome, dimensão e "como pontua") estão em meta.blocos[].criterios: use-os para os rótulos,
  não escreva os textos no app.js.
- "link" no critério existe só quando há (ex.: a lei do salário).

Hoje: 26 estados com índice geral; só o MT sem índice geral (bloco do governo a conferir: a folha pede CAPTCHA).
O bloco que tem nota (a Assembleia, no MT) aparece mesmo assim.

O que fazer no site
-------------------
1. A página /indice passa a ser o "Índice de Transparência" (secIndice no site/app.js e a versão em HTML do
   publicacao/gerar.mjs, com a divisão em publicar/dados/indice/ que já existe), lendo indice_transparencia.json:
   - estados do maior índice para o menor; estados sem índice geral no fim, com "a conferir";
   - em cada estado: o índice geral e, para cada bloco (Governo, Assembleia), o índice do bloco com completude e
     facilidade em barras (como hoje);
   - ao abrir um estado: cada bloco com os seus critérios (nota, prova, link quando houver, "como pontua") e o link da
     fonte oficial do bloco; o bloco do governo também leva à página do governador (como hoje), e o da Assembleia à
     lista dos deputados estaduais daquele estado (quando o estado está em assembleias.json; hoje 16 estados);
   - o método (meta.como) na própria página; a pergunta (meta.pergunta) no topo.
2. Manter os endereços: /indice e /indice#indice-sp (abre o estado). Os links que já existem (cabeçalho, lista dos
   governadores, página de cada estado) continuam; vale pôr um também na lista dos deputados estaduais.
3. Textos neutros: a nota é da FONTE (o que o órgão publica e como), não da pessoa no cargo. Não usar "pior/melhor
   governo", "esconde" etc. Ex.: "O que a fonte mostra" (completude) e "Como dá para obter" (facilidade).
4. Os eventos de medição (ver_indice, abrir_indice) podem continuar com os mesmos nomes; se quiser, um parâmetro
   "bloco" ao abrir um bloco.
5. Quando a página nova estiver no ar, me avise (chat dos dados): aí o site/dados/indice.json antigo pode sair do
   gerador. Até lá ele continua sendo gerado.

Não editar os arquivos de dados (site/dados/*.json, dados/indice/*.json): as notas são mantidas à mão no chat dos
dados. Se achar uma nota estranha, anote e me passe.
